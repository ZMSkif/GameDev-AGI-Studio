description: Prepare a revision-linked checkpoint for pausing or resuming a piece in a fresh studio session.
argument-hint: "<GitHub Issue or PR URL>"

Use the `studio-handoff` skill for the piece in `$ARGUMENTS`. For a pause, capture the worktree, revision, remaining acceptance line and next step. For a resume, read the existing checkpoint and verify the current revision, ownership and worktree before editing. Use the current Issue or PR when authorized.
